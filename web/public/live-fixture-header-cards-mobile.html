Fixture cards above the live header · iOS

The desktop/iPad page gained a fixture-card switcher strip. On a phone the header is already tall (back row, big scorehead, 5 tabs), so the strip has to earn its vertical space. Five takes below, roughly most info → most compact, all switching between the four Game Week 1 fixtures with Mordor SFG vs Atlético Bilbo open. Each keeps the production violet header, scorehead and tabs underneath.

ANamed mini-cards
Closest to the desktop strip: each card shows both crest + team name + score over a small state line. Most informative, but names must truncate hard at this width. Horizontally scrolls.
BScore chips (crests only)
Drop the names: overlapping crest pair + score as a pill, active chip flips to solid white. Roomy on one line, three-plus fixtures visible, but you read teams by crest.
CPeek carousel + dots
One wide card centred with the neighbours peeking, plus page dots. Names and scores fit because only one card is prominent; you swipe the strip like the deck itself.
DInline on the back row
Zero extra band: the back chevron shares its row with compact abbrev + score chips. Cheapest on vertical space, keeps the big scorehead intact — but tiny targets.
ESegmented strip
A fixed segmented control: equal-width segments (crest pair + score), active segment underlined. No scroll for a 4-fixture week, reads as one tidy unit tied to the tabs below.
